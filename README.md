# Focus

Display-only focus screen for iPhone (PWA). Task + countdown, nothing else.

- `./set-task.sh "AMS report" 40` — update task.json, commit, push.
- task.json older than 12 h → the page shows a task box + 15/25/45/60 picker instead.
- Tap task to edit; tap timer to pause/resume; tap DONE to reset.
